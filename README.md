# لوحة تحكم المتجر الإلكتروني المتكاملة (Store Admin Hub)

نظام إداري متكامل وعصري لإدارة المتاجر الإلكترونية، صُمم وفق أعلى معايير تجربة المستخدم والتصميم الحديث بنظام دعم ثنائي اللغة (العربية والإنجليزية) مع التوجيه التلقائي (RTL / LTR).

---

## 🚀 الميزات الرئيسية

1. **لوحة التحليلات والمؤشرات (Analytics Dashboard)**
   - إجمالي الإيرادات ومعدل نمو المبيعات.
   - حجم الطلبات ومتوسط قيمة السلة (AOV).
   - مخطط بياني تفاعلي للإيرادات الأسبوعية مع إحصائيات كل يوم.
   - توزيع المبيعات حسب الفئات والمنتجات الأكثر مبيعاً.
   - تتبع فوري لآخر طلبات الشراء.

2. **إدارة المنتجات والمخزون (Products Catalog)**
   - استعراض الكتالوج بنمطي العرض (جدول تفصيلي أو بطاقات بصرية).
   - تصفية متقدمة حسب الفئة، حالة المخزون، أو البحث بالاسم ورمز الـ SKU.
   - إضافة وتعديل المنتجات عبر لوحة منزلقة سلسة (`ProductFormSheet`).
   - تنبيهات فورية للمخزون المنخفض أو النافد.

3. **إدارة العروض وقسائم التخفيض (Offers & Coupons)**
   - إنشاء أكواد ترويجية مخصصة بنسبة مئوية أو قيمة نقدية ثابتة.
   - تحديد شروط الحد الأدنى للطلب وتواريخ انتهاء الصلاحية.
   - قياس معدل استخدام كل كود مع إمكانية نسخه فورا بضغطة زر.

4. **سجل المشتركين والعملاء (Subscribers & Customers)**
   - تتبع بيانات العملاء والمشتركين في النشرات البريدية.
   - إحصائيات القيمة المالية التراكمية لكل عميل (LTV).
   - تصدير مباشر للبيانات بصيغة `CSV` للتكامل مع منصات التسويق.

5. **شاشة قفل الأمان (Lock Screen)**
   - قفل سريع للوحة التحكم لحماية الخصوصية عند الابتعاد عن الشاشة.
   - لوحة أرقام PIN تفاعلية تدعم لوحة المفاتيح ورمز المرور السريع.
   - محاكاة فتح القفل بالبصمة الحيوية أو رمز الطوارئ (`1234`).

6. **تصميم تفاعلي متجاوب (Responsive Layout)**
   - درج جانبي منزلق (`AdminDrawer`) ملائم لكافة أحجام الهواتف والشاشات اللوحية.
   - شريط ملاحة علوي (`AdminHeader`) للتبديل بين الفروع، البحث السريع، وتبديل اللغة.

---

## 🛠️ الملفات والبنية البرمجية

- `src/App.tsx`: نقطة الربط الرئيسية للواجهة وتوزيع المكونات.
- `src/useAdminBridge.ts`: إدارة الحالة العامة والبيانات والربط بين الأقسام.
- `src/AdminHeader.tsx`: الشريط العلوي والإشعارات وتبديل اللغة والبحث.
- `src/AdminDrawer.tsx`: القائمة الجانبية المنزلقة للأجهزة المحمولة.
- `src/Nav.tsx`: الروابط الأساسية وأيقونات التنقل.
- `src/LockScreen.tsx`: شاشة القفل والأمان برمز PIN.
- `src/AdminAnalyticsDashboard.tsx`: لوحة القيادة والمخططات البيانية.
- `src/ProductsManager.tsx`: جدول وفلاتر المنتجات.
- `src/ProductFormSheet.tsx`: نموذج إضافة وتعديل المنتج السلس.
- `src/AdminOffersManager.tsx`: إدارة العروض وقسائم الخصم.
- `src/SubscribersList.tsx`: سجل العملاء وتصدير CSV.
- `src/ui.tsx`: مكتبة عناصر واجهة المستخدم القياسية (Buttons, Cards, Badges, Modals, etc.).
- `src/Sheet.tsx`: مكون الدرج المنزلق الجانبي.
- `src/motion.ts`: إعدادات وتأثيرات الحركة والانتقال.
- `src/useMediaQuery.ts`: خطاف التجاوب مع مقاسات الشاشات المختلفة.
- `src/format.ts`: دوال التنسيق المالي والزمني والأرقام.
- `src/admin.css`: الأنماط المخصصة وشريط التمرير والتأثيرات الزجاجية.
